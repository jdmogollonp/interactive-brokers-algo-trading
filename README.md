# Interactive Brokers Algo Trading

Scripts and notebooks for algorithmic trading with the Interactive Brokers API.

## Contents

| Folder | Description |
|--------|-------------|
| `Basics IB` | Getting started with IB API |
| `Advanced IB` | Advanced trading strategies and execution |
| `Algotrading in Python` | Python-based algorithmic trading implementations |
| `Technical analysis in python` | Technical indicators and analysis tools |
| `Notebooks` | Jupyter notebooks for exploration and backtesting |
| `Crypto` | Cryptocurrency trading scripts |
| `Examples FinRL` | Examples using FinRL reinforcement learning library |

## Requirements

- Interactive Brokers account with API access
- TWS or IB Gateway running
- Python 3.x
- `ib_insync` or `ibapi`
